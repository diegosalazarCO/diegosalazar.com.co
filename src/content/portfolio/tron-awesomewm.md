Tron is a Lua theme for awesomeWM on Linux.

If you wish to create a custom theme, copy this file to `~/.config/awesome/mytheme.lua` and replace `beautiful.init(gears.filesystem.get_themes_dir() .. "default/theme.lua")` with `beautiful.init(gears.filesystem.get_configuration_dir() .. "mytheme.lua")` in your `rc.lua`.
